# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses [Semantic Versioning](https://semver.org/).

## [1.7.0] - 2026-11-15

### Changed

- The Solver's memory limit now follows the phone: 1 GB on Android phones that report 8 GB of RAM, 700 MB on iPhones and phones that don't report their RAM, and 400 MB on phones with 2 GB or less (previously 400 MB for every phone).

### Added

- "Solve anyway" for Spots above the phone's safe limit, up to a 2 GB cap, with a warning that the page may crash. The setup stays in the URL, so a crash only loses the solve.

## [1.6.0] - 2026-11-15

### Added

- A "new version is ready" banner with Refresh and Later. The app checks for updates whenever it comes back to the foreground.

### Changed

- A new version of the service worker now waits for the Refresh tap instead of taking over open pages, so a page never mixes old and new files.

## [1.5.0] - 2026-11-15

### Added

- An invitation to add the app to the home screen on phones: a one-tap install on Android Chrome, step-by-step instructions on iOS and other Android browsers. Dismissing it stores a single flag so it never comes back.

## [1.4.0] - 2026-11-15

### Added

- Page-view counting with Vercel Web Analytics (no cookies). The service worker leaves analytics requests to the network.

## [1.3.1] - 2026-11-15

### Added

- README, MIT license and contributing guide.

### Fixed

- A selected button in the Ranges pickers turned unreadable (light text on a light background) on hover.

## [1.3.0] - 2026-11-15

### Added

- French translation at `/fr`, with a 🇬🇧 EN / 🇫🇷 FR switch that keeps the current tool and setup. A phone set to French opens the French app.
- French number formatting (`12 500`, `81,9 %`) and a French Glossary. A Glossary search finds terms by their English or French name.

### Changed

- Solver and range errors are translated: the maths returns error codes and the UI writes the text.

### Fixed

- The language switch kept the setup only once the page had loaded; it now keeps it on the first tap.
- Typing in the Glossary filter removed the `#term` from the address.

## [1.2.0] - 2026-11-15

### Added

- A Blind level in the Solver's preflop line, so level 1 (50/50) pots use the real blinds.
- The Solver's place in the game tree and the selected hand class now live in the URL, as does the selected hand class in Ranges.

### Changed

- "Position" replaces "seat" everywhere.
- Button styles and number formatting are shared across tools. The progress bar no longer animates, and grid labels no longer use a text shadow.

### Fixed

- The Equity player-kind control was below the 44px touch target.

## [1.1.0] - 2026-11-15

### Added

- Glossary: plain explanations of about 90 poker terms and abbreviations used in the app, grouped by topic, with a filter and a link per term.

## [1.0.0] - 2026-11-15

First release: a mobile-first No-Limit Hold'em study tool that runs entirely in the browser, installs as an app and works offline.

### Added

- **Advisor**: the Chart's answer for your exact hand, Position, stack and the action before you, with a verdict card and the size to use. Postflop: equity against estimated ranges, pot odds, required equity, SPR and a heuristic verdict, with "Open in Solver".
- **Equity**: 2 to 8 players, each a hand, a range or random, with board and dead cards. Exact enumeration when feasible, Monte Carlo otherwise, in a Web Worker.
- **Ranges**: the preflop Charts by Situation, Position and Stack tier on a 13×13 grid, push/fold grids showing the largest stack each hand still pushes or calls, and a scratchpad that copies range strings.
- **Solver**: a discounted-CFR heads-up postflop solver for turn and river Spots, and small flop Spots. It fills both ranges from a preflop line and shows the strategy grid, the game tree, and combos, EV and equity per hand class.
- Seeded baseline Charts (Open, Vs open, Vs limpers) for three Stack tiers, validated at build time.
- Push/fold Charts from 1 to 15bb, generated by a deterministic chip-EV Nash script that matches published heads-up results.
- A fast 5–7 card hand evaluator and a range-string parser and formatter.
